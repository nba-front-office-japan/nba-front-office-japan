# フォント

- `NotoSansJP-Bold.ttf`: Noto Sans JP Bold（Google Fonts）。記事のシェア用画像（`lib/og/share-card.tsx`）で使う。
  - ファイルを小さくするため、英数字・記号・かな・JIS第1/第2水準漢字など（Shift_JIS/CP932で表せる文字）だけに絞ることがある（`scripts/subset-og-font.py`）。
